# FinanceW FP1a // Household Scenario Lab

This is an in-memory, read-only STRATEGIES workspace.
It compares an upfront-investment option plus monthly running costs and
explicitly valued time against a monthly alternative over 1/3/5/10/30 years.

MINE, SHARED, MOM, GRANNY and FAMILY are labels only. They do not grant
financial access, prove household membership or represent real accounts.
Switching context resets the fictional example and discards the preview.
The source of every result is HYPOTHETICAL_INPUT_ONLY and nothing is saved.

Use after reviewed merge and operator-approved local update:
Finance → STRATEGIES → choose context → edit inputs → choose period →
CALCULATE HYPOTHETICAL COSTS.

Checks:
node tests/finance/test_finance_household_planning.mjs
python3 tests/finance/test_finance_household_planning_contracts.py
