## IMPLEMENTATION

P52 introduces a **genuine Fedora 44 built and detached OpenPGP-signed RPM** that packages the existing P47–P50 STATUS-only host exactly as already merged, without modifying any of those modules.

- `tests/phone/p52_signed_phone_status.spec`: new PHONE-only `post-apollo-phone-status-ci` noarch RPM with an exact six-file allowlist: root-owned four immutable-mode 0555 Python modules, one 0644 package-local copy of the inert systemd unit, and one 0644 canonical systemd unit under `/usr/lib/systemd/system`. `AutoReqProv: no`, no scriptlets, triggers, dependency on Identity, service activation, keyring or production auth. The systemd unit has no `[Install]` section and still requires a dedicated, separately provisioned nonroot service user and test marker. Neither is created by RPM.
- `tests/phone/p52_build_signed_phone_status.sh`: explicit GitHub-hosted CI/root/container guard, refuses nonempty output and missing source, builds in Fedora 44 using `rpmbuild` with shebang rewriting disabled, lists exactly six RPM payload files, **unpacks the built RPM** and checks every real payload byte and file mode against the PHONE source. Generates a disposable GPG RPM-signing key in restricted ephemeral `/tmp`, exports only public key, fingerprint and detached artifact SHA-256 list, signs the package using `rpmsign`, and wipes builder-local private material at exit. It does not enroll this key as an independent operator release root.
- `tests/phone/p52_verify_installed_phone_rpm.sh`: executes in a **separate fresh Fedora 44 container** with its own RPM database. Requires correct payload role, no scripts/triggers, and **missing/untrusted signature before** explicit CI public-key import. After import verifies the actual RPM signature, installs the RPM in the disposable Fedora container, validates `rpm -V --nomtime`, root UID/GID, modes/link counts, exact on-disk source and both unit copies, and confirms installed isolated Python still exposes strictly non-authorizing P47/P50 STATUS. Removes the package via actual `rpm -e` and checks every package module and unit disappeared. The import/install/erase happens only inside the disposable Fedora container, never on an operator workstation.
- `test_phone_personal_signed_rpm_p52.py` and `social-phone-p52-signed-fedora-rpm.yml`: deny-only exact package/spec guard, shell syntax, exact roster/unit/regression tests, Fedora 44 build and separate verify/install/erase, plus P51 read-only systemd observer/P45 mainline lock. No artifacts with private signers are uploaded.
