# SUPPORT // META APOLLO LOGOS // POST-APOLLO FAMILY

If you are not sure where something belongs, start here.

The Meta Apollo Logos // Post-Apollo Family uses a few different paths depending on the kind of relationship you are trying to have with the project.

## SOMETHING BROKE

Use **BUG // RELATIONSHIP PROBLEM**.

Describe what happened, what relationship you expected the system to preserve, and what happened instead.

Use the repository's issue template when available.

## YOU HAVE AN IDEA

Use **FEATURE // IDEA**.

Describe what you want to add or change and what relationship the idea is trying to create, strengthen, simplify, or change.

## YOU FOUND A SECURITY OR PRIVACY PROBLEM

Read **SECURITY.md** first.

Security reports should be handled privately whenever possible.

Do not publish passwords, tokens, private information, exploit details, or a working proof of concept in a public issue.

## YOU WANT TO CONTRIBUTE

Read **CONTRIBUTING.md**.

Code is welcome, but it is not the only useful contribution. Documentation, testing, research, evidence, design criticism, experiments, artwork, examples, bug reports, and careful observations can all help.

## YOU WANT TO DISCUSS DESIGN, ARCHITECTURE, OR PHILOSOPHY

A normal issue is fine when the discussion belongs to a specific repository.

If GitHub Discussions or another official family-wide discussion space becomes available later, broader conversations may move there.

Questions, disagreement, criticism, and correction are welcome when they remain in good faith.

## YOU WANT TO USE THE PROJECT COMMERCIALLY

Read **LICENSE.md**.

Community use and commercial use are different relationships.

Original Meta Apollo Logos // Post-Apollo material does not automatically grant commercial permission. Commercial use may require a separate written agreement with the copyright holder.

Inherited or third-party material remains governed by its own license.

## YOU ARE NOT SURE

Open an issue and explain what you are trying to do.

You do not need to know the project's internal vocabulary before asking for help.

A maintainer can help route the question from there.

---

**The goal is to make it easy to find the right door without making people learn the whole building first.**
