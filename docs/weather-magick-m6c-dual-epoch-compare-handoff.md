## HOW TO USE

After authorized PR merge and separately approved Fedora installation:

1. Open Weather Station > MAGICK > ASTROLOGY > ZODIAC > COMPARE, or INDEX > ASTROLOGY > TRANSITS.
2. If the chart has no verified JPL samples, use the existing pair/date/span controls and CALCULATE with the configured kernel.
3. The outer cyan ring is the reference at the **first source UTC** by default; the inner magenta ring is the current selected sample. The screen shows both actual UTC timestamps and measured chart longitudes. The same-body connections are illustrative comparisons, not physical orbits.
4. Use existing sample navigation/time drag or wheel to choose another current timestamp. Select **PIN REF** to pin that genuine source sample as a new reference, and continue moving the current sample.
5. Choose **WHEEL** to return to the original zodiac graphic. The reference remains ephemeral and is reset when the source changes.
