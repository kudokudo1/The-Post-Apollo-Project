# M46e1 // Retire redundant mounted six-stock reader
FinanceW previously instantiated FinanceStockHistoryReadService even though its price results were no longer used. Its monitoring property served only as a lifecycle witness for worldwide controls. The root now supplies a boolean derived from menuOpen and selectedMainMode; the Stocks pane additionally checks its own effective visibility. Opening/collapsing controls does not toggle this gate. No new reader or process is introduced.
The six-stock service, reader CLI, stock catalog and hub range endpoint remain in source for backward compatibility and rollback. The SEC filing-date reader and its hub route are unchanged. No claim that other external callers have been migrated or that the old reader is deleted from the repository.
Legacy demo access is not silently restored: the old Apple/MSFT demo token path is separate from validated worldwide listing selection. A future explicit demo source requires entitlement and identity provenance review. No new provider calls, quota activation, disk writes or external account data in this change.
Rollback: revert this PR only to restore the former service mount; no storage migration. Stacked on M46d1 to preserve its chart regression correction; parent must be accepted first.
