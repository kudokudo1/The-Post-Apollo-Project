## IMPLEMENTATION

services/phone/PhonePersonalSignedTrustP37.py implements a PHONE-specific receipt **consistency consumer**. It verifies actual Ed25519 signatures over domain-separated canonical frames with two separately supplied 32-byte public keys on disposable CI. It **always** returns productionEnabled=false, vaultWriteEnabled=false, humanConsentVerified=false and installedHostVerified=false.

- **Host fixture:** fixed CI-only role and audience. Its signature binds the frozen exact save-request hash, independent challenge hash, signed release and complete host-evidence digests, release epoch/sequence and time window.
- **Consent fixture:** different CI-only role and signature key. It signs the same request/challenge hashes, the exact host-receipt frame hash, a reviewer-evidence commitment, and a short time window beginning after host issuance and ending by host expiry.
- **Exact PHONE request:** action LINK/FAVORITE/NOTE/UNLINK, phone-profile UUID, observed unique BlueFerry owner, session ref, snapshot epoch, HMAC of selected contact, HMAC of the exact pending edit, metadata revision, external challenge SHA256, release-floor epoch/sequence and request nonce. Private contact values and notes do not enter the signed frames.
- **Parsing and validation:** exact key roster, canonical bounded JSON, no duplicate keys, separate public-key roles, Ed25519 signature verification with distinct domain prefixes, exact digest/purpose/audience bindings, integer epochs/sequences and 60-second maximum lifetime.

Even both correct signatures yield only SIGNED_FIXTURE_PAIR_MATCHED, with **no permission grant**. Both test keys, expected inputs and evidence digests are generated by the disposable caller and are not proof of independently enrolled production origin. The module has no signer, source observer, keyring, consent source, DBus/IPC, provider call, challenge ledger, vault read/write, or CLI.

Adversarial tests deny wrong signer/role, tampered frames, different domain, wrong profile/provider owner/snapshot epoch/session, changed selected-card or pending-edit HMAC, revision, action, challenge, nonce, release floor, expired frames, reordered consent, wrong host-frame hash, duplicate/noncanonical JSON, unknown fields and invalid signature bytes.
