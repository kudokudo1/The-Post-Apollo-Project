# CHANGELOG // META APOLLO LOGOS // POST-APOLLO FAMILY

This changelog records **meaningful changes to the project**, rather than every individual commit.

Git preserves the detailed history.

The changelog preserves the history that is useful to a person.

A changelog entry should explain the **transformation**, not merely repeat the commit message.

## UNRELEASED

### Added

New capabilities, surfaces, tools, relationships, or other significant additions.

### Changed

Existing behavior, structure, presentation, or relationships that meaningfully changed.

### Fixed

Bugs, regressions, broken behavior, or relationships that were repaired.

### Removed

Things intentionally removed, retired, replaced, or made obsolete.

### Continuity / Provenance

Changes where migration, inheritance, history, origin, compatibility, or continuity particularly matters.

## RELEASES

Released versions will be added below when a project state becomes meaningful enough to name, preserve, and point back to.

A release is a **named continuity point**, not a requirement for every merge or commit.
