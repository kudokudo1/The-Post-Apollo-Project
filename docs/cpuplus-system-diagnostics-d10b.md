# DOC 3 D10b — General SYSTEM diagnostic workshop

Operator decision: SYSTEM → ALL is a stable general diagnostic workspace,
not the selected resource row's actuator. All ten qualified instrument
selectors are available in the common workshop. General draft and shared
session ownership are retained. Two rows of five at narrow widths, one row
of ten when there is room; right-aligned selector rail matches the left
status block. Existing resource scopes retain their original selector counts,
colors and calibration. MEMORY DIAG focuses on Quickshell memory capture
and the existing live host RAM context. Its independent draft does not
overwrite the general draft. SWAP retains its separate observer and existing
management menus. The original internal ALL core calibration scope is retained
for compatibility, but is not mounted by either production SYSTEM navigation
path. The public SYSTEM → ALL workspace uses the full SYSTEM scope.

The original five core observers can participate in a qualified multi-capture
workflow. Host CPU, GPU, disk I/O, swap I/O and network I/O remain standalone
captures; mixed sequential workflow sets are supported. Selecting a standalone
instrument clears other selected instruments. No new collectors, resident
polling, simultaneous hardware capture authority, or protected operations.
Reports and history stay shared. Exact-report notifications route to SYSTEM
→ ALL after verifying the report identity. Desktop acceptance remains separate.
