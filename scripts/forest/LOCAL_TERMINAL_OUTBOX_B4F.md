# Forest Core B4f // Synthetic Local Terminal Outbox

PATIENT: The-Post-Apollo-Project
STAFF: Forest backend DOC, external Hospital-compatible; no live registration
ROOM: Forest B4f local writer event source ↔ Connections C3e/C4b/C5
STATE: EXPERIMENTAL, DISPOSABLE FIXTURE ONLY
PRODUCTION: HOLD

## IMPLEMENTATION // What bytes actually change

B3 already writes the assistant response, session revision and attempt
COMMITTED status atomically to one local SQLite file. A process can crash after
that COMMIT but before C5 acknowledges a receipt. B4c/B4d/B4e rightly keep
the protected issuer state UNKNOWN_HOLD.

B4f adds an explicitly initialized, disposable SQLite
`forest_local_terminal_events_b4f` table. It is deliberately not installed
or migrated automatically.

An **opt-in** synthetic B3 writer
`ForestTurnBridge(..., synthetic_terminal_outbox=True)` refuses startup
unless the table exists with foreign-key checks enabled. Existing B3/B4
fixture constructors remain unchanged and are not production-ready.

- COMMIT: B3's original SQLite transaction inserts assistant reply,
  advances session revision, moves original RESERVED attempt to COMMITTED
  and **in that same transaction** appends a unique local terminal event.
  If event insertion fails, the entire transaction rolls back.
- ABORT: a still-RESERVED attempt transitions to ABORTED with an
  accompanying local terminal event in the same SQLite transaction.
  Calling ABORT again, or after COMMIT, creates no second event.
- The event ID is generated by the writer. Owner, Tree, session, user turn,
  attempt, model, expected revision, reply ID and timestamp are selected
  from B3's persisted original state, not client JSON. No prompt, model
  response, title, signed claim, or fake client permit ID is written.
- SQLite CHECK, unique attempt, FK, and UPDATE/DELETE-denial triggers
  discourage accidental editing. These cannot stop a privileged database
  writer or whole-file restore.
- `ForestLocalTerminalOutboxInspector` checks B4e original turn/reply
  lineage first and reads owner/session-scoped local event metadata,
  without running a model or touching C5, keys, services or the desktop.
  The current B4a host may use a *separately verified* local actor to call
  this in a later reviewed interface; this PR does not introduce a
  network/listener/wire action.

All read-only outputs deliberately retain
`c5Settlement=UNKNOWN_HOLD`,
`custodyAuthenticated=false`, `terminalReceiptAuthenticated=false`,
`safeToRetryInference=false`, `safeToReleaseRevocation=false`,
`productionAuthority=false`. A local event is not C5 receipt evidence.

## HOW TO USE // Tests only

    python3 -m unittest discover -s tests/forest -p 'test_local_terminal_outbox_b4f.py' -v

Fixture bootstrap order:

1. Create temporary SQLite and `bootstrap_synthetic(db)` for B1.
2. `bootstrap_attempts_synthetic(db)` for B3.
3. `bootstrap_local_terminal_outbox_synthetic(db)` for B4f.
4. Construct B3 writer with `synthetic_terminal_outbox=True` and
   an injected fake clock/streamer.
5. Inspect local result using `ForestLocalTerminalOutboxInspector(journal)`.

Do not execute bootstrap or any migration on a personal/local installed
Forest database. No real model is needed for the tests.

## VERIFY // Negative matrix

Tests cover atomic local COMMIT, positive local ABORT, failed outbox INSERT
rolling back reply/revision/status, failed ABORT insert leaving RESERVED,
commit-vs-abort conflicts, duplicate terminal attempts, direct edit/delete
trigger denial, rereading after DB reopen, read-only SQLite, wrong owner/
session, invalid original/model references, lost C5 ACK after local COMMIT,
no inference retry, no prompt disclosure, and restored old whole-file
snapshot reverting COMMITTED to RESERVED without external proof.

B3/B4a/B4b/B4c/B4d/B4e regressions run in dedicated CI.

## WATCH OUT FOR // Serious security limits

- The outbox is in the **same unprotected local database** as the attempt.
  Restore/rewrite that database and both can be forged consistently.
  This is local transaction coupling, **not antirollback custody**.
- An event is not bound to a genuine C5 permit, operation epoch, protected
  writer key or root. Current Connections V1 signed session/receipt fixtures
  and DOC 3 #2267 deny-only reconciliation are NOT issuer authority.
- Event reads use caller-supplied host owner values; they are only safe when
  an independent, protected C3e/C4b native host authenticates the requester,
  installed release, process identity, active session/seat and original writer.
- ABORTED local event means only local B3 status transitioned with no
  assistant reply. It is **not** ROLLBACK_CONFIRMED by independent issuer.
- A crash **inside** original transaction can leave RESERVED with no event;
  no expiry-based or automatic replay/revocation-release is allowed.
- Midstream provisional text can already be disclosed before consent loss.
  Do not confuse local COMMIT integrity with cancellation/disclosure policy.
- No personal prompts, protected storage, native signer, service listener,
  permission transfer or UI integration is activated by this PR.
- Existing unfenced B3/B4a paths remain **synthetic only**, not production
  bypasses. Reviewer must not reinterpret them as installed host protection.
