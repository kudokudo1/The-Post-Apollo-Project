This source-only gate deliberately refuses insufficient or ambiguous normalized trace records. It cannot verify their origin and does not perform a native trial. A future independently reviewed disposable Silverblue KVM collector must establish the original helper's exact blob, same boot, util-linux executable inode, PID/start identity (prefer pidfd), protected lock custody and actual syscall actor. Trace capture must be scoped to the original actor in a private trace instance with a common ordered clock, validated kernel symbols/event schemas, no dropped/overrun events, and bounded evidence. Require actual x86_64 swapoff entry, actual try_to_unuse entry (or reviewed kernel-equivalent function), verified signal generation targeting the same original actor while the function is executing, negative EINTR function return and negative EINTR syscall exit. The normalized entry value zero is a sentinel, not a return value. Signal event target identity must be resolved by the collector, not confused with emitting task identity. Do not treat signal generation as guaranteed delivery or prove causality from timing alone. Actual function availability, permitted trace facilities, signal timing and return behavior must be checked in the guest; if unavailable or operation completes too quickly, report UNKNOWN/BLOCKED, never fabricate evidence. No artificial delay in helper or kernel, no disabled security policy, no occupied-extension admission bypass, no automatic retry after ambiguous effects. A separate fresh VM can be used for another explicitly reviewed attempt.

Only after native evidence is established, independently check actual kernel swap state, exact file identities, durable intent/outcome, retained history, lock release and recovery refusal. No replay or recovery clearing. If empty extension cannot be interrupted, keep this gate unresolved rather than loosen production admission. Physical SSD power loss, arbitrary root exclusion and guarded reclamation remain distinct requirements. This PR adds only pure source qualification logic and synthetic negative fixtures; no production code, trace setup, signal injection or live execution.
